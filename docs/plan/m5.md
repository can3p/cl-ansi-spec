# M5 — The HTML site

Planned 2026-11-28.  Whole-milestone `plan-critic` (opus): 2026-11-28,
findings folded in below ("Critic").  Runs in parallel waves
(`docs/process.md`, "Parallel waves").

Goal (`docs/architecture.md`, phase 5): a static HTML site generated
from the document model, our own design, deployed to GitHub Pages by
CI, with the whole export, the JSON Schema and the sample export
published beside it.  The site is one consumer of the model: nothing in
`src/model/` or `src/export/` changes shape for it.

## Decisions taken at planning

Each is a rule the steps implement; 5.0 writes them into `docs/site.md` (planned),
and the step that implements one keeps its section true.

- **Nothing from the HyperSpec.**  No session opens a HyperSpec page
  during M5, for design or anything else (`AGENTS.md`).  Structure,
  navigation, URLs, page names, markup and style are designed here from
  the model alone.  Every grouping the site shows is one the sources
  make: chapters and sections, the glossary's letter groups, the
  sources' own index (`:index-entry` nodes); the site invents no
  alphabetical symbol pages.  Every word rendered comes from the model
  or from this repository's own short labels (navigation, "Contents",
  "Index", the about page), fixed in 5.0.
- **Package.**  `cl-ansi-spec/html` (`src/html/` (planned), tests `tests/html/` (planned)),
  phase 5 beside `cl-ansi-spec/export`.  It reads the model in process
  (CLOS nodes, `walk-nodes`, the registry's introspection) and uses
  `cl-ansi-spec/export` only to publish the data (`write-whole-export`,
  `write-sample-export`).  No third-party dependency: the emitter is our
  own.
- **Emitter.**  `src/html/emit.lisp` (planned): elements built only by the
  emitter's constructors and written as HTML5 with every attribute and
  text escaped, so every page is well formed by construction (void
  elements listed once).  UTF-8, `<!doctype html>`, `lang="en"`.  No
  inline `style`; classes name meaning (`term-ref`, `param`), never
  looks.  A page is streamed to its file, not held as a tree.  While a
  page is written the emitter records every `id` and every internal
  `href` it wrote, which the link check reads (no file is parsed back).
- **Site paths.**  Ids become file names and fragments by one injective,
  reversible encoding (`site-name`, `src/html/pages.lisp` (planned)), never the
  export's file-name rule (which maps `1+` and `1-` to one name): `a`–`z`,
  `0`–`9` and `-` stay, every other UTF-8 byte (upper case, `/`, `*`,
  `+`, `.`, `_`, …) becomes `_XX` (two upper-case hex digits), so names
  differing only by case stay apart on case-insensitive file systems.
  `*print-base*` → `_2Aprint-base_2A`.  A test encodes every id of the
  whole model and finds no collision; decoding gives the id back.
- **Renderers** are an extension table, not a `case`: `define-renderer`
  (`src/html/render.lisp` (planned)), one form per node kind in its area's file.
  A test checks every kind of the registry (`node-kinds`) has exactly
  one renderer, with a ratchet per model area
  (`tests/html/unrendered-<area>.sexp`, the areas of
  `src/model/nodes-<area>.lisp`; empty at milestone close).  A string
  inline is text, escaped by the emitter.  A node without a renderer is
  a problem of the site report, never skipped silently.
- **Pages** (the *page map*, `src/html/pages.lisp` (planned), built once from the
  model before any page is written).  `page-of` gives every node the
  page it is rendered on: the page of the nearest ancestor that has one.
  Nodes with a page of their own:
  - the document: `index.html` (title, cover, front matter, chapters,
    the data, `about.html`);
  - a chapter: `chapters/<name>.html` (its own blocks, then the table of
    its sections and entries);
  - a section of level 1: `sections/<name>.html`, with every section
    below it on the same page;
  - every dictionary entry, wherever it stands (a dictionary section, a
    chapter): `entries/<name>.html`; the page of its container lists it;
  - a glossary group: `glossary/<name>.html` (the letter the sources
    give it); `glossary/index.html` lists the groups;
  - the index: `index/<name>.html`, one per group the sorted index
    entries' first character gives (letters, then one page for the
    rest), `index/index.html` lists them;
  - `about.html` (text fixed in 5.0: what the site is, how it is built
    from `spec/tex/` and `patches/`, the commit, the sources' notice of
    `spec/PROVENANCE.md`, the data files).
  Pages are written by *page kinds*: `define-page-kind` (pages.lisp)
  registers, for a node kind, the function that writes its page; each
  step registers the page kinds of its area and 5.7 only runs them.
  Figures, sections below level 1, glossary entries and anchors live
  on their page under a fragment `<prefix>-<site-name>`: `sec`, `fig`,
  `g`, `idx`; two in one page stop the build.
- **Links.**  `(href-to target from-page)` (pages.lisp) gives the
  relative URL, with fragment, from a page to a target of any target
  kind the registry declares (`:entry`, `:glossary`, `:chapter`,
  `:section`, `:figure`); the page shell's navigation goes through it
  too.  A reference whose `:target` is nil renders as its text in a
  `class="unresolved"` span, never a link.  The site build checks every
  recorded `href` against the pages and ids recorded.
- **Labels.**  An entry's kind is shown as the sources write it (the
  `\ftype` text, "Standard Generic Function"), a part by its `:title`,
  a `:none` part as "None." (the sources' word), section and figure
  numbers as the model holds them.  Where the model keeps only an enum,
  5.0 records the label of each value beside the renderer, read from
  the sources (`make vocab NAME=\ftype`).
- **Math** is MathML Core (`<math>`, `display="block"` for a display):
  - a math character by class: letters `mi` (`mathvariant="normal"`
    when the model's character is not from the italic family), runs of
    digits `mn`, classes `:bin`, `:rel`, `:op`, `:open`, `:close`,
    `:punct` `mo`; a noad's nucleus that is a list, `mrow`;
  - sub/superscripts `msub`/`msup`/`msubsup`; with `:limits`,
    `munder`/`mover`/`munderover`; a radical (`:delimiter` "√")
    `msqrt`;
  - a fraction `mfrac` (`linethickness="0"` for `:no-rule`, the
    thickness converted to `px` otherwise), its delimiters stretchy `mo`
    around it in an `mrow`; `\left`/`\right` stretchy `mo`;
  - a style change `mstyle` with `displaystyle` and `scriptlevel`; a
    `:math-choice` renders the choice of the style in effect;
  - inlines inside a formula (`:code`, `:emphasis`, BNF notation) in
    `mtext`;
  - a display's equation number is outside the `<math>`: the display is
    a `div class="display-math"` holding the `<math>` and a
    `span class="eqno"`, before it for `:number-left`.
  No script.
- **Hidden notes** (`:editor-note`, `:reviewer-note`, `:hidden t`) are
  rendered in a closed `<details>`, never dropped.  Issue anchors render
  as small markers, index entries as empty anchors `idx-…` the index
  pages link to.
- **Spans.**  The element of a section, entry, figure or glossary entry
  carries `data-src="<file>:<line>"` (the patched tree's coordinates); no
  source viewer.
- **Style and script.**  One stylesheet of our own
  (`src/html/assets/site.css` (planned), copied verbatim), light and dark by
  `prefers-color-scheme`, readable at phone width.  The site works
  without JavaScript; one small script of our own
  (`src/html/assets/filter.js` (planned)) filters the index pages by a typed
  prefix.
- **Data** published beside the site: `data/export/` (the whole export),
  `data/sample/`, `data/schema/model.schema.json`.  `make site` (planned) builds
  the model once and writes the pages and the data.
- **Deploy.**  `.github/workflows/pages.yml` (planned): top-level `permissions:
  contents: read`; a build job on push to `main`, `pull_request` and
  `workflow_dispatch` (install SBCL, `make site` (planned), report the site's
  size, `actions/upload-pages-artifact@v3`); a deploy job only on push
  to `main` and only `if: github.repository == 'can3p/cl-ansi-spec'`
  (`pages: write`, `id-token: write`, environment `github-pages`,
  `actions/deploy-pages@v4`), `concurrency: {group: pages,
  cancel-in-progress: false}`.  It needs the repository's Pages source
  set to "GitHub Actions", a setting the owner makes.
- **Tests.**  Renderer tests build a real line range with
  `build-fixture` and render it, asserting markup.  The whole-site test
  (5.7) renders every page of the whole model into a temporary
  directory after `forget-job-runs`, without `data/`, within a budget
  of 60 s beyond the model build, and checks the link records.

## Critic

Whole-milestone critic (opus, 2026-11-28), all accepted:

1. The export's file-name rule collides (`1+`, `1-`) → an injective
   site encoding of its own, tested on every id.
2. `href-to` without the page it is written on cannot be relative →
   `(href-to target from-page)`, the navigation included.
3. Placement and page writers vague → `page-of` for every node,
   `define-page-kind`, entries directly in chapters get pages too.
4. MathML Core gaps (no `mlabeledtr`, style changes, choices, fraction
   delimiters, fonts, digits, radicals) → rules in the decisions.
5. Whole-site test cost → streamed pages, in-memory link records, no
   `data/` in the suite, a time budget.
6. Tiering → about text and labels fixed in 5.0 (opus); 5.1 *Critic*
   full; the external checker named (vnu.jar).
7. Pages workflow → permissions, concurrency, repository guard,
   pinned actions, a build on pull requests, size reported.
8. Alphabetical symbol pages risk the HyperSpec's structure → the
   sources' own index and glossary groups instead.
