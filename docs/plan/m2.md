Steps (each separately reviewable, in this order; tools and tests grow with

- [x] **2. Vocabulary inventory tool** (`make vocab`, no expansion, uses
      M1 tokens): every macro defined in each file, its uses per file and
      per job, simple aliases, and source counts of candidate vocabulary
      entries.  Its output seeds the vocabulary and the step-14 invariants,
      and tells which primitives and quantities the later steps must get
      exactly.  Plan-critic findings, step 2 — it is a *survey* that labels
      its own uncertainty, not a second expander:
      - Package `cl-ansi-spec/inventory` (`src/inventory/`), using only the
        reader's exports; the tool `tools/vocab.lisp` prints.
      - Definitions: `\def`/`\gdef`/`\edef`/`\xdef` with `\global`/`\long`/
        `\outer` prefixes, `\let` (with or without `=`), `\chardef`-like
        and `\new…` allocations, `\font`.  A definition inside another's
        body (`##` parameters, `\deffigrefs` at setup-aux.tex:1100) is
        recorded as nested under that macro: it exists only once the outer
        one expands.  `\def\a{\b}` is a simple alias.  Each definition and
        alias records its group depth.
      - Uses: outside definitions ("text") and inside bodies ("body"),
        counted apart.  Names defined nowhere in the spec are "plain" if
        `plain.tex` defines them, else primitives.
      - Uncertain regions: a literal `\catcode`, `\obeylines` or
        `\obeyspaces` outside a body starts one; it ends with the group it
        is in, or at the end of the file at top level (chap-0.tex:24,
        setup-aux.tex:968).  Definitions and uses in it are flagged.
        Macros whose bodies change catcodes are listed, not followed.
      - Jobs: a chapter file plus its literal `\input`s, transitively,
        and the calls of input macros (`\includeDictionary{dict-x}`, found
        while implementing: without it no dictionary file is read); each
        file once per job; computed (`\input\jobname.toc`), repeated and
        missing (`chap-N.fig`) inputs are listed.
      - `make vocab [JOB=…|FILE=…] [NAME=…] [LIMIT=…]`: one line per name
        (kind, defining file:line, text/body/uncertain counts); `NAME=`
        gives the details of one macro.
      Tests: fixtures for each definition form, nesting, aliases, a
      catcode region inside and outside a group, `\input` closure; a
      cross-check over the real sources against grep-derived counts.
      *Docs:* `docs/vocabulary.md` (Choosing entries), `docs/architecture.md`
      (package table), AGENTS.md commands
- [x] **3. Quantities.** Integers with TeX's overflow rules, dimensions in
      scaled points, glue specs with stretch/shrink orders, TeX's exact
      arithmetic (`x_over_n`, `xn_over_d`, `nx_plus_y`, decimal rounding)
      and printing (`\the` of dimens and glue).  Golden tests derived from
      the TeX rules.  Plan-critic findings, step 3:
      - First files of package `cl-ansi-spec/expand` (`src/expand/`).  Integers are CL integers
        within ±(2^31−1), dimensions integers in sp within ±(2^30−1); glue
        is an immutable struct (width, stretch, shrink, orders 0–3), since
        registers will hold it under the save stack (step 4); mu glue is
        the same struct, tagged.
      - Overflow follows TeX: operations return their result and an
        overflow flag (TeX's `arith_error`); the scanner (step 6) owns the
        error and its recovery ("Arithmetic overflow", "Dimension too
        large").  `\divide` by 0 is an overflow.
      - Units as data and pure functions here: pt, pc, in, bp, cm, mm, dd,
        cc, sp as exact ratios, and `true` through `\mag`; em/ex take the
        font's `\fontdimen` (0 unless assigned) as an argument; mu (1/18
        quad) likewise.  Step 6 only parses the keywords.
      - Exactness: decimal fractions as TeX rounds them (`round_decimals`,
        at most 17 digits), `\the` printing as TeX's `print_scaled` (and
        `fil`/`fill`/`filll`, ` plus`/` minus` only when nonzero).  Rules
        come from *TeX: The Program* (cited by section number, nothing
        copied).  `\romannumeral` and `\number` belong to step 6.
      Tests: property tests of `x_over_n`, `xn_over_d`, `nx_plus_y` against
      CL rational arithmetic at the 2^15/2^30/2^31 boundaries; print/read
      round trip for every sp in 0..65535 and a stride beyond; goldens
      (1in = 72.26999pt, 1cm = 28.45274pt, 1bp = 1.00374pt, 1dd = 1.07pt,
      1cc = 12.8401pt, 16383.99999pt is the largest dimension).
      *Docs:* `docs/tex-fidelity.md` (Exact), `docs/architecture.md` (package table/status)

- [ ] **7. Conditionals.** All of TeX82's (`\if`, `\ifcat`, `\ifx`,
      `\ifnum`, `\ifdim`, `\ifodd`, `\ifvmode`, `\ifhmode`, `\ifmmode`,
      `\ifinner`, `\ifvoid`, `\ifhbox`, `\ifvbox`, `\ifeof`, `\iftrue`,
      `\iffalse`, `\ifcase`), condition stack, skipping nested

      *Docs:* `docs/tex-fidelity.md`
- [ ] **8. Main control: assignments and grouping.** Assignments with
      prefixes, `\afterassignment`, `{}`/`\begingroup`/`\aftergroup`,
      `\uppercase`/`\lowercase`, `\message`/`\show*`,
      `\openout`/`\write`/`\closeout`/`\immediate` (writes become events

      `\ignorespaces`; TeX's modes tracked (`\ifmmode`, `\leavevmode`,
      `\par`) without building lists.
      *Docs:* `docs/tex-fidelity.md`
- [ ] **9. Presentational events and `make events` tool.** The
      per-primitive table: every remaining primitive has its operand
      syntax scanned and becomes a presentational event (`\par`, glue,
      `\hbox{...}` as begin/end, `\char`, math shifts, sub/superscripts,
      rules, ...) or is dropped — each choice listed.  Text runs carry the
      current font identifier.  Box registers hold the events emitted
      inside them, with specified, tested semantics for everything the
      setup files rely on: `\box`/`\copy`/`\unhbox`/`\unvbox` replay;
      `\lastbox` removes the last box event; `\vsplit` takes the whole
      box; `\wd`/`\ht`/`\dp` are 0 unless assigned; `\lastskip`,
      `\lastpenalty`, `\lastkern` look at the last event of the current
      list; `\pagetotal`, `\prevdepth` are 0 (no metrics).
      *Docs:* `docs/events.md`, `docs/tex-fidelity.md` (the per-primitive table), AGENTS.md (`make events`)
- [ ] **10. Alignments.** `\halign`/`\valign`: preamble with `\tabskip`,

      *Docs:* `docs/events.md`, `docs/tex-fidelity.md`
- [ ] **11. Plain TeX loads.** All of `vendor/plain/plain.tex` runs with no

      *Docs:* `docs/tex-fidelity.md` (Jobs)
- [ ] **12. Vocabulary mechanism.** Entries keyed on meanings, observe

- [ ] **13. The vocabulary.** The entries themselves (a data file, each

      `\DefineFigure`, `\deffigrefs`/`\defsecrefs`).  Content hidden by

      flagged, by its entry: the model keeps everything the sources say.
      *Docs:* `docs/vocabulary.md`, `docs/model.md` (any schema consequence)
- [ ] **14. Whole spec.** Every chapter job runs with no error;
      generated files (`chap-N.fig`, `.tc`, `\jobname.toc`/`.idx`) resolve

      counts of each vocabulary entry (from step 2) equal its event counts;
      files no job reaches are reported (`setup-boxfig.tex`); a hash of
      each job's event stream is kept as a snapshot test.
      *Docs:* `docs/events.md`, `docs/architecture.md` (Status)
